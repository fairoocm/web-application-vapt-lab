# Web Application VAPT Lab

## Project Overview

This project is a structured learning workspace for practising web application security assessment in an authorized training environment.

## Objectives

- Learn a repeatable web application testing methodology.
- Understand request and response analysis with Burp Suite.
- Practise permitted service discovery and security checks.
- Learn to validate potential vulnerabilities safely.
- Document evidence, risk, and remediation recommendations.

## Tools

- Kali Linux
- Burp Suite
- Nmap
- Nikto

## Planned Methodology

1. Confirm authorization, scope, and lab availability.
2. Document the lab environment and testing restrictions.
3. Perform only the permitted discovery and assessment tasks.
4. Validate observations in the authorized lab.
5. Record sanitized evidence and remediation guidance.
6. Retest fixes where possible.
